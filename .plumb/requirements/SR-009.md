---
id: SR-009
title: A review verdict is recorded per document and angle against a bundle
statement: cv record-review --workspace ROOT --bundle outputs/SLUG/rNN/bundle.json --document resume|cover_letter
  --angle ANGLE --verdict pass|findings|unavailable [--findings PATH] [--reviewer TEXT] appends one verdict
  to reviews.json beside the bundle, storing the bundle hash and the SHA-256 of the exact artifacts of
  that document; it refuses an angle that the document does not have, a findings verdict without a findings
  file, or a bundle that is not loadable.
examples:
- id: EX-1
  given: a built revision
  when: a pass verdict for the resume factual angle is recorded
  then: reviews.json holds that verdict with the current hashes of the resume artifacts
- id: EX-2
  given: a built revision
  when: a findings verdict is recorded without a findings file
  then: the command refuses
- id: EX-3
  given: a built revision
  when: a verdict names the angle persuasiveness for the resume
  then: the command refuses, since persuasiveness is a letter angle
proof:
  plan: in a Claude Code session on the fictional showcase profile, build a revision, let the reviewers
    record their verdicts, then open reviews.json beside the bundle
  kind: live-session
