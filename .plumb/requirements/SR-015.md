id: SR-015
title: The Claude Stop hook holds a turn's end while the master profile...
statement: On a Stop event in the bound workspace, the Claude hook returns a block decision naming the
  missing claim IDs when the configured master profile does not name every evidence claim; it returns
  nothing when the master is current, when no master is configured, or when stop_hook_active is true.
examples:
- id: EX-1
  given: a configured master profile that lacks one claim ID
  when: the Claude hook receives a Stop payload
  then: the output is decision block with a reason naming that claim ID
  quote: enforced through hooks
  prompt: 8072950ce96d253e
- id: EX-2
  given: a master profile that names every claim ID
  when: the Claude hook receives a Stop payload
  then: the output is empty
- id: EX-3
  given: a missing claim ID and stop_hook_active true
  when: the Claude hook receives a Stop payload
  then: the output is empty
- id: EX-4
  given: a workspace that names no master profile
  when: the Claude hook receives a Stop payload
  then: the output is empty
proof:
  plan: in a live session, add a claim without touching the master profile and see the stop held with
    the claim named
  kind: hook
