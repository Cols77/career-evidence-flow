id: SR-020
title: The startup guide names the environment's interpreter
statement: The generated RESUME_TOOLKIT.md commands and the doctor package check use the absolute path
  of sys.executable without resolving symlinks, so a Linux virtual environment whose python is a symlink
  to the system interpreter stays the pinned interpreter.

- id: EX-1

  when: the startup guide is generated
  then: its commands name the symlink path, not its target
  quote: supported both with linux and windows
