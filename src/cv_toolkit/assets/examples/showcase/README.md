# Synthetic visual showcase

Every identity, employer, date, achievement and qualification in this example is fictional. These records exist to exercise rendering and validation, never to supply evidence about a real candidate. The source registry declares `synthetic_fixture`; onboarding must keep this workspace synthetic.

`resume.md` covers dated employers and roles, an undated Earlier Experience group, projects, skills, education, Unicode punctuation and an explicit `[pagebreak]`. The identical source is used by every visual style.

From an installed toolkit, create a copy with `cv init ../showcase --example showcase`, or generate the complete visual comparison directly with `cv gallery --output ../resume-gallery --format both`.
