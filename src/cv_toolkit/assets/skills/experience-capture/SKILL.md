Interview only for material gaps in owner-supplied evidence. Reuse sufficient existing answers, and permit unknown or declined answers. Persist actual supplied facts with source IDs; preserve uncertainty, ownership, limitations, prototype maturity and team attribution. Never promote job requirements to applicant facts. A correction requires explicit correction storage and superseding the old claim.

Run `cv validate-evidence --workspace ROOT --evidence profile/evidence.json --registry profile/registry.json` after edits. Evidence schema_version is string "1". Publication permission is separate from storage. Claim sources must join the supplied registry. Registry fingerprints are declarations, not authenticated freshness. This command performs structural validation, not independent semantic approval.
