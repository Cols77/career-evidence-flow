id: SR-030
title: cv regenerate builds the next revision from an edited release
statement: cv regenerate --workspace ROOT --from outputs/SLUG/rNN --diff prints, building nothing, the
  unified diff of the revision's top-level resume.md and cover-letter.md against its frozen sources; without
  --diff it copies them over the application's sources, even when those changed after rNN, and builds
  the next free revision with the same output format and policy, running the same checks.
examples:
- id: EX-1
  given: an edited r06/resume.md
  when: cv regenerate runs from r06 with --diff
  then: it prints the changed lines and nothing is built or copied
- id: EX-2
  given: an edited r06/resume.md
  when: cv regenerate runs from r06
  then: r07 is built from the edited text, applications/SLUG/resume.md equals it, and r07's checks ran
- id: EX-3
  given: r07 already exists
  when: cv regenerate runs from r06
  then: it builds r08
- id: EX-4
  given: applications/SLUG/resume.md changed after r06 was built
  when: cv regenerate runs from r06
  then: the application source is replaced by r06's edited copy and the new revision is built from it
