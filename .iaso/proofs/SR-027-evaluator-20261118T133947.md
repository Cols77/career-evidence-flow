Verdict: verified

Checked: On the fictional showcase profile I built an HTML revision with no verdicts (plus a fictional letter). I ran the review step live on Claude Code (claude -p with the saved review-angles workflow) and on Codex (codex exec, following the installed application-materials skill), each on its own fresh copy. Read ONLY the rendered resume artifact and the frozen job text in inputs/; never open evidence, registry, sources, notes, projection or requirements'. Caveats: the Codex stream did not log spawn items, so the subagent spawning rests on the agent's own run notes, the 12 wait calls and the 10 recorded verdicts. Visual review was not exercised with real page images on either host.
